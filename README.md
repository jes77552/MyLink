## ✨ 주요 기능
1. **프로필 조회 및 반응형 UI**
   - 모바일, 태블릿, PC 모든 디바이스에서 최적화된 반응형 디자인
   - 간결하고 모던한 링크트리 스타일 UI 제공

2. **관리자 권한 및 프로필/링크 관리**
   - 일반 방문자에게는 읽기 전용으로 깔끔하게 링크 목록만 제공
   - 관리자 전용 **[프로필 수정]** 버튼을 통해 편집 모드 진입
   - 편집 모드 활성화 시 **`+ 새로운 링크 추가하기`** 전용 버튼 노출
   - 링크 추가, 수정, 삭제 및 실시간 반영

3. **Firebase Authentication 연동**
   - Google OAuth 간편 로그인 지원
   - 이메일/비밀번호 가입 및 로그인 기능 제공

4. **GitHub Pages 24시간 자동 호스팅**
   - GitHub Actions 및 `gh-pages`를 활용한 정적 웹 배포
